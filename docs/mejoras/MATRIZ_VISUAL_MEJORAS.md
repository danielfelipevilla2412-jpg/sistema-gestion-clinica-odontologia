## 💡 LECCIONES APRENDIDAS (st-odo-01 y st-odo-02)

### **✅ Qué Funcionó Bien**

1. **Integración Backend → SQL Server directo**  
   → Queries optimizadas, no ORM excesivo

2. **Componentes autocontenidos**  
   → HTML + CSS + JS en misma carpeta, fácil mantener

3. **Progressive Enhancement**  
   → Funciona sin JS, mejora con JS

4. **Data attributes para interacción**  
   → `data-id`, `data-status`, etc. para filtros dinámicos

5. **LocalStorage para preferencias**  
   → Toggle de vista persiste entre sesiones

### **⚠️ Qué Mejorar**

1. **Código duplicado**  
   → Crear componentes compartidos desde el inicio

2. **Testing manual**  
   → Automatizar con Playwright/Cypress

3. **Sin WebSockets**  
   → Polling cada 60s funciona, pero WebSockets sería ideal

4. **CSS muy específico**  
   → Reutilizar más utility classes

5. **Sin i18n**  
   → Hardcoded en español, agregar soporte multiidioma
